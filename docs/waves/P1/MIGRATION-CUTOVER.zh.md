## 失败恢复

开放新写入前可撤销候选并恢复旧入口。开放后先冻结新入口、保存全部新变化/墓碑/隐私/用量/维护登记，优先修复前滚；如需回旧服务，必须实现受控回迁并证明反向兼容及零丢失再开放。无法证明时保持维护页和私有状态，禁止盲切旧快照。

保留旧发布包、配置加密备份、数据库/文件和版本清单直至生产验收、一次恢复演练及保留策略完成；不删除旧仓库/备份，不继续为旧版开发功能。最终迁移报告只公开脱敏结论和工件hash，私有逐项对账交给维护者。

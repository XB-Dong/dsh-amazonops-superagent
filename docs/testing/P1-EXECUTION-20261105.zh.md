## 原生功能与模型

有限期库存跟进沿同一实际Ticket等待、接收业务变化、提出attention、接受人工答复、保存一份内部草稿并最终投递。规则投递与实际接单分别记账；重开策略可重评，真正接受的auto风险窗口不重复派工。可信auto闸门覆盖启动、恢复、候选投递和每次写工具授权，关闭时旧auto worker不能继续执行。

真实模型使用独立合成资料与账本：完整watch链和独立冷启动observe正例分开记录。65请求中63次用量核实，2次取消保留未知预留；不声称旧master的语义误忽略已恢复。测试控制的时钟/CAS、编码误重复、缺参纠正、模型误忽略及所有失败证据保留，零自动provider重试。

同情景对照中，持续跟进在风险变化后不需要重复业务背景；一次性对照需要补一次背景。包含人工决策/结束时总消息为2对3，假模型请求为11对15，不能据此声称总交互、速度或成本更低。

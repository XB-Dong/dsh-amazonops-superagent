# P1 验收与证据计划

当前P1产品验收全部not_run。准备审核、JSON/链接/隐私检查不算产品或生产通过。P0的237测试和59验收只作基线。

每项P1验收记录requirement/case、候选完整SHA、锁文件/产物/upstream/补丁hash、OS/Node/DSH、步骤、时间/时区、命令/退出码、实际结果、私有原工件hash及独立审核处置。原文、真实业务ID/指纹、会话、地址、密码和SSH/API凭据不入公开Git；生产证据公开时只给脱敏摘要。

## 分层

- 领域/迁移行为：真实Red→Green→必要重构；新增队列/指纹/写入栅栏/反向迁移反例，已有计算规则回归。不将安装或观察夹具故障当产品Red。
- 原生：实际Source→Engine/Ticket/Mandate→Assignment→DSH Session→工具→Report→outbox；等待、用户答复、事件续办、停止、到期、重复、重启与隐私闭包。禁止mock loop或UI状态替代。
- 平台：Windows保留全套，增加Linux实际子进程/目录权限/安装和原生测试；精确候选CI全绿。代理HTTP/RPC/WS和Secure cookie、host/origin伪造、匿名/退出/管理工具拒绝。
- 浏览器：登录、公网WS、责任/attention/补充/停止/重试、筛选草稿、规则observe解释、watch跨重启，验证持久化与后台实际效果，不能只看按钮。
- 真实模型：独立测试账本和合成数据，一条完整有限期库存跟进闭环（首次授权、后续业务变更、真实attention与答复、工具成功、精确结果投递）；必要单规则评估实测。零自动模型重试，未知usage保守留账，不重置历史，不借日常账号，不自设累计消耗上限。完成明确验收后停止无用调用。
- 生产：冻结最终快照、零遗漏对账、实际TLS/登录/来源/重启/备份恢复、切换后建议持久化、旧入口不可写、单服务/单维护权威。合成迁移通过不能填生产对账。
- 收益：同一合成情景记录人工重复提示/决策、遗漏/重复、耗时和usage，没有对照或收益不成立时如实报告。

独立审核针对精确候选，分别记录独立实际执行与阅读作者证据。不得以准备材料完整提前将acceptance标passed，所有强制问题关闭后才能完成P1。

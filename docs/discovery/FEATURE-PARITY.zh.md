# 功能复现基线

依据 ccagent 固定源码 bc964298d49ad399ae325f57068c9149502b8c62、现行需求与最新交付报告。发现 Agent parity_inventory 独立只读检查；本次没有运行旧产品测试。

## 页面及模型入口

旧界面有 13 个主导航入口，另加设置与登录：工作台、运营助手、任务清单、工作日历、学习笔记、改进反馈、经验与记忆、活动日历、数据报表、库存补货、发货协同、广告分析、使用说明。

正式插件为 cc-operations，含 9 个工具和 cc-approved Provider。页面可写能力多于模型工具权限；迁移不自动扩大模型写入范围。

## 必须保留的行为

| 需求 | 核心行为 | 不可遗漏的边界 |
| --- | --- | --- |
| CC-ENTRY-001 | 中文欢迎、实际能力目录、例句、短说明 | 欢迎不调用模型；离线仍可浏览与表单操作；状态不伪报 |
| CC-HARNESS-001 | 官方循环、流式、原生会话恢复/压缩及取消 | 页面断开与显式取消分开；未知 usage 不当零；截断不能冒称完整 |
| CC-TASK-001 | 草稿/确认、编辑、勾选、状态、站点起止排期、用时 | ID/来源/CAS；完成/取消锁结构；分钟 0–1440 或空；北京时间创建日期筛选；未知日期末尾；切状态保留未存输入 |
| CC-TASK-COPY-001 | 完整清单读取、预览、可选标题、区分大小写的字面替换、新草稿 | 每页 4 完整步骤；模型结果不超过 6000 UTF-8 bytes；重置勾选/用时/完成/排期；冲突和失败无孤儿；重放不重复；来源删除闭包 |
| CC-WORKLOG-001 | 完成任务成为工作日历，按所选时区查看和修正实际用时 | 计划/实际分开；未填不算零；缺完成日不猜；跨午夜和 DST |
| CC-NOTES-001 | 独立纯文本笔记增改查删及重启持久化 | 关闭学习不影响手动笔记；不自动入模型/Skill；CAS/幂等/范围/恢复不复活 |
| CC-ACT-001 | 活动四阶段任务、到期内部提醒、人工确认生效/恢复、取消 | 重启补提醒一次；取消后不新增；IANA/DST；经验提前 4 小时可配置，不当平台通则 |
| CC-DATA-001 | 已有销量/广告 CSV 预览、映射、质量检查、内容指纹批次 | 缺日期/值不当零；标识字符串；日期不晚于 asOf；店铺/站点/币种规范化；重复导入不叠加 |
| CC-INV-001 | 连续 7 日均值或有原因人工需求、版本；按日入库/活动/缺货损失及补货 | 不足 7 日不猜；预留不双扣；分数均值不逐日虚增；在途早于快照拒绝 |
| CC-SHIP-001 | 批次池/日期窗/唯一分配、四前置、字段复用、双号、累计到货/取消释放 | CAS、不超分配、SKU 和日期窗；单号唯一；到货不倒退/超量/发运前录入；没有真实外部建单 |
| CC-ADS-001 | listing/campaign/adGroup/searchTerm 分组、CTR/CPC/CVR/ACOS/ROAS、预算/利润和导出 | 零分母为 null；币种隔离；广告组保留 campaign；6 位微单位精度；缺成本利润未知；归因用报表 asOf |
| CC-FEEDBACK-001 | 明确反馈/有限中文规则捕获、来源去重、精确归并计次、补充和撤回 | 语义相似不擅自合并；原始反馈非执行指令；修订和撤回不丢；私人登记不入 Git |
| CC-MEMORY-001 | 明确确认事实、更正替代、推断分开、范围检索和确定性摘要 | 引用/否定不当确认；事实权威；摘要可重建；压缩不丢纠正；删除后不能重放复活 |
| CC-SKILL-001 | 成功清单派生、L0 规则回放后启用、L1 待确认、停用/撤销及 Provider | 成功须人工明确确认；正文/来源/hash/范围校验；L2 拒绝；旧会话/恢复不能绕撤销 |
| CC-HISTORY-001 | 日期追加、确认变更、版本化审阅包和撤回/替代 | stable changeId；新补充未经确认不覆盖旧确认；不持 GitHub 凭据、不自动改源码 |
| CC-ANALYSIS-001 | 运营摘要供模型只读查询 | 来源、日期、范围、截断/遗漏信息真实；通用 BI/任意代码仍排除 |
| SA-NATIVE-001 | 原生 Source→Engine→Ticket→Assignment→DSH worker→业务回执→Channel | 留存上游真实对象和持久事件；不以命名相同的自建执行器替代；页面 CRUD 不强制走模型 |
| SA-ACCESS-001 | 全入口认证/Origin、scope、运营角色、工具护栏、CAS/幂等 | 原生流式/RPC/附件/管理路由同样保护；模型的 scope 参数不授予权限 |
| SA-RECOVERY-001 | 业务/编排/会话/文件/账本协调恢复和迁移副本核对 | 删除撤销先重放；预算只合并不回退；取消/恢复不重复写；不触碰生产数据 |
| SA-LOCAL-001 | Windows 本机独立运行；loopback、独立状态和端口 | 不依赖未经验证的 WSL；不动旧目录/云/自动任务；不共享写入生产数据库 |

排除：CC-CUSTOMER-001、个人手动排序、通用 Excel/商品映射/BI 和外部自动写入。旧候选中的已落地 CSV 与摘要仍在上表，不能整体排除。

# 多 Agent SDD / TDD 开发规则

本项目的实际执行规则。Leader 维护规格、共享契约、依赖锁、集成、状态和交付；每个写者独立 `codex/` 分支和仓库外 worktree，禁止并发修改同一路径。只读审核不需要写入 worktree。

## 派发前

先读需求与现有代码，完成并自审 Context Map，再冻结可独立执行的任务包：根目标、精确基准 SHA、规格版本、责任人、允许路径、依赖、可观察验收、修复与停止条件、交付格式。未知上游接口先做真实宿主探针，确认后冻结契约。

## 各角色的完成门槛

| 角色 | 实现边界 | 必须交付的验证 |
| --- | --- | --- |
| 前端 | 原生客户端 slot；仅共享 DTO；表单、加载、错误、空状态和中文说明；不导入数据库或业务实现 | 类型/构建、纯展示规则回归、实际浏览器操作和持久化；复制需完整预览；模型离线表单可用；不能以 SSR/截图代替交互 |
| 后端 | 领域规则、单一写入服务、纯查询、CAS/幂等、scope/来源；业务任务独立于学习和编排任务 | 计算/时区/金额、并发、事务失败、重复与变参冲突、删除和恢复反例；GET 不能暗中消耗后台工作 |
| 原生底座 | 保留官方 Runtime/Engine/Store/Effects/Session，受限 preset 与 agent-local guard，版本补丁和许可证可追溯 | 真实 Windows 宿主、工具回调、流式、取消、压缩、HMR/重启、协调备份/恢复；不以 mock loop 冒充原生 |
| 集成 | 可信 Source、稳定 operationId、全入口身份与权限、工具/Provider、模型账本和恢复 | HTTP/RPC/WS 负向、真实本地 SSE 端到端、旧会话/撤销/删除不复活、必要真实模型与实际用量 |
| 独立审核 | 只读检查精确候选 SHA、规格和证据；作者自检不能替代审核 | 按触发、位置、期望/实际、级别、证据与未知返回；Leader 修复后逐项关闭，未解决强制项不能完成 P0 |

## 测试与证据

先写目标行为并实际运行 Red，再实现 Green，必要时重构。迁移不变行为保留回归；安装错误不算行为 Red，事后写的回归不伪称先失败。测试覆盖行为与风险，不为低影响改名增加镜像测试。

普通完整测试由 `node scripts/test.mjs` 串行发现，清洗模型、GitHub、SSH 和旧服务环境变量；实际调用只能到本地假模型。必要真实模型使用独立本机数据和账本，零自动重试，保留超时、单轮循环保护；不自设累计费用/请求/token 上限，不删除失败和未知用量。

每项验收绑定 requirement/case、实现与上游版本、环境、步骤、命令/退出码、实际结果和原始证据摘要。Git 仅留脱敏索引与 hash，原始会话、运行数据、凭据和个人路径留在仓库外。旧系统的通过不能作为新系统的通过。

两次同根因定向修复后先重新诊断并记录架构判断，累计修复不换名清零。类型检查、构建、受影响测试通过后再集成；最终执行完整离线套件、浏览器、必要模型、独立审核和 CI。固定 59 个强制验收全部完成后才关闭 P0，不把未通过项挪到下一波。

## 隔离与交付

仅新仓库和新私有 home/state/data/端口。禁止 cloud/SSH、旧源码/运行目录/自动任务写入、真实 Amazon/ERP 副作用。启动和恢复拒绝目录链接逃逸。产品进程不继承研发 GitHub/SSH 凭据。

交付包括可重复安装/构建/启动、精确提交、上游和补丁、测试与模型用量、已知范围及本机入口。状态必须和 [P0 状态](../waves/P0/state.json)、[验收矩阵](../testing/acceptance.json)一致。
